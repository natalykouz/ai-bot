# AI-бот для проверки договоров и форматирования HTML

Внутренний Telegram-бот команды «Глазами инженера».  
Функции: проверка договоров по чек-листу, форматирование HTML-кода для сайта.

---

## Стек

- Python 3.13
- aiogram 3.x
- OpenAI API (gpt-4o-mini по умолчанию)
- python-dotenv, python-docx, pdfplumber

---

## Переменные окружения (.env)

```
BOT_TOKEN=             # токен Telegram-бота от BotFather
OPENAI_API_KEY=        # ключ OpenAI API
OPENAI_MODEL=gpt-4o-mini  # модель OpenAI по умолчанию (fallback если пользователь не выбрал)
ADMIN_IDS=             # user_id администраторов через запятую — только для первого запуска
BOT_PASSWORD=          # начальный пароль доступа — только для первого запуска
```

## Константы (config.py)

Лимиты на размер входящего текста задаются в `config.py` — при необходимости изменить, редактировать напрямую в коде:

```python
MAX_CHARS_CONTRACT = 20000  # для проверки договоров
MAX_CHARS_HTML = 20000      # для форматирования HTML
```

## Выбор модели

При проверке договора пользователь выбирает модель через inline-кнопки:

- **Быстрая (gpt-4o-mini)** — дешевле, справляется с большинством договоров
- **Умная (gpt-4o)** — точнее, лучше для сложных или нестандартных документов

Для форматирования HTML модель фиксирована: gpt-4o-mini.

## Интеграция в MGI Admin Bot

Бот разработан как отдельный модуль для последующей интеграции.

**Что нужно перенести:**
- `handlers/contract.py` — все хендлеры и FSM-состояния
- `services/openai_service.py` и `services/html_service.py` — логика обращения к OpenAI
- `config.py` — загрузка промптов и констант
- `prompts/` — папка с текстами промптов

**Авторизация:**  
В существующем боте уже реализована проверка доступа по роли пользователя (по номеру телефона в базе сайта). Функции этого бота должны быть доступны только пользователям с ролью **«администратор»** — подключить к существующей проверке.

## Доступ по паролю

Все функции бота (кроме ввода пароля) закрыты, пока пользователь не введёт правильный пароль.

**Как это работает:**
- При первом запуске бот создаёт файл `prompts/auth.json` из `ADMIN_IDS` и `BOT_PASSWORD` (см. `.env`). Пароль хранится в виде хеша (sha256 + соль), не в открытом виде.
- Любой пользователь, не прошедший проверку, при любом сообщении получает запрос ввести пароль. После верного пароля его `user_id` сохраняется в `allowed_users` в `prompts/auth.json` — повторно пароль вводить не нужно.
- Администраторы (`admin_ids`) имеют доступ всегда, без пароля.

**Смена пароля без доступа к коду:**

```
/setpassword новый_пароль
```

Команда скрытая (не в меню), доступна только администраторам. Новый пароль сразу сохраняется в `prompts/auth.json`, сообщение с открытым текстом пароля бот удаляет из чата. Изменения работают без редеплоя.

Чтобы добавить или убрать администратора — команды `/addadmin user_id` и `/removeadmin user_id` (см. раздел «Команды администратора» ниже). Правка `prompts/auth.json` напрямую больше не требуется.

⚠️ Файл специально хранится в папке `prompts/`, а не в отдельной `data/` — на Railway к одному сервису можно подключить только один persistent volume, и он уже примонтирован на `prompts/`. Поэтому переиспользуем его вместо второго volume.

---

## Persistent storage для промптов и авторизации

⚠️ **Важно при деплое.**

Папка `prompts/` должна быть смонтирована как постоянный volume (persistent storage).

Причина: в боте реализована команда `/setprompt`, которая позволяет обновлять тексты промптов через Telegram без редеплоя, а также `/setpassword` и список допущенных пользователей — они хранятся в `prompts/auth.json`, в той же папке. Если она не смонтирована как volume — все изменения сбросятся при следующем редеплое.

## Команды администратора (скрытые)

Команды не отображаются в меню бота — известны только администраторам.

### /getprompt — скачать текущий промпт

```
/getprompt contract   ← скачать промпт проверки договоров
/getprompt html       ← скачать промпт форматирования HTML
```

Бот отправляет файл `.txt` — его можно отредактировать и загрузить обратно через `/setprompt`.

### /setprompt — обновить промпт

```
/setprompt contract   ← обновить промпт проверки договоров
/setprompt html       ← обновить промпт форматирования HTML
```

### /setpassword — сменить пароль доступа к боту

```
/setpassword новый_пароль
```

Доступна только администраторам (`admin_ids` в `prompts/auth.json`). Подробнее — раздел «Доступ по паролю» выше.

После команды бот ждёт файл `.txt` с новым текстом промпта. Изменения применяются сразу без редеплоя.  
`/cancel` — отменить действие.

### /addadmin, /removeadmin — управление администраторами

```
/addadmin user_id       ← сделать пользователя администратором
/removeadmin user_id    ← забрать права администратора
```

Доступны только действующим администраторам. `/removeadmin` не даст удалить последнего администратора — иначе управлять ботом через Telegram станет некому.

## Лимиты и стоимость

- Максимальный размер текста: 20 000 символов
- gpt-4o-mini: ~$0.002 за запрос
- gpt-4o: ~$0.02 за запрос
- При превышении лимита бот сообщает об ошибке без обращения к API
