# UTM.md

## Москва глазами инженера

### UTM

- `utm_source`: `emailmgi`

### Правило автоматической подстановки

Для всех новых ссылок в рассылке «Москва глазами инженера» автоматически добавлять параметр:

    utm_source=emailmgi

Если URL уже содержит UTM-параметры, не дублировать `utm_source`.

## Петербург глазами инженера

### UTM

- `utm_source`: `mail_pgi`

### Правило автоматической подстановки

Для всех новых контентных ссылок в рассылке «Петербург глазами инженера» автоматически добавлять параметр:

    utm_source=mail_pgi

`email-regular-spb` используется для системной ссылки подразделения и не является рабочей меткой контентных ссылок.

Если URL уже содержит UTM-параметры, не дублировать `utm_source`.

---

## Казань глазами инженера

### UTM

- `utm_source`: `email_kgi`
- `utm_medium`: `email` — для ссылки на календарь/страницу событий.

### Правило автоматической подстановки

Для контентных ссылок рассылки «Казань глазами инженера» автоматически добавлять:

    utm_source=email_kgi

Для ссылки на календарь/страницу событий использовать:

    utm_medium=email&utm_source=email_kgi

Если URL уже содержит UTM-параметры, не дублировать их.

## Общее правило автоматической подстановки

При сборке новой ссылки ChatGPT автоматически определяет подразделение и добавляет соответствующий `utm_source`, даже если во входных данных SMM UTM отсутствует.

Используются следующие значения:

- Москва глазами инженера → `utm_source=emailmgi`
- Петербург глазами инженера → `utm_source=mail_pgi`
- Казань глазами инженера → `utm_source=email_kgi`
- Онлайн-лекторий → `utm_source=emaillektoriy`

`utm_campaign` и другие параметры не добавляются автоматически, если для них не задано отдельное рабочее значение.

## Правило формирования URL мероприятия

Для ссылки на мероприятие:

1. взять URL мероприятия;
2. определить конкретное событие;
3. использовать конкретный `event_id`;
4. добавить дату события в параметре `startDate`, если она предусмотрена URL мероприятия;
5. добавить UTM соответствующего подразделения;
6. итоговая ссылка должна вести именно на конкретное событие.

Для Казани используется формат:

    https://kzn.engineer-history.ru/tour/{slug}?startDate={YYYY-MM-DD}&event_id={ID}&utm_source=email_kgi

Пример:

    https://kzn.engineer-history.ru/tour/arhitektura-socgoroda?startDate=2026-08-08&event_id=34289&utm_source=email_kgi

Для ссылки на календарь Казани используется:

    https://kzn.engineer-history.ru/events/{date}?utm_medium=email&utm_source=email_kgi

Итоговая ссылка мероприятия всегда должна вести на конкретное событие, а не только на общую страницу мероприятия.
