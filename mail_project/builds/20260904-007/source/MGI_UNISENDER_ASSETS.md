## Технический placeholder для переменных изображений

- `6fea2cfd-955f-4aab-89d6-c3cb52deb89f.png`
  https://img.hiteml.com/en/v5/user-files?userId=7788090&resource=himg&disposition=inline&name=6ejkwuxu7f3gmgb4a6h4mzmz4k4q8gk381pdsfs9xjyp6gfksdfpc8kehgmmajpik1rm5ser7bexn8y6c8a86j3xa8h9csjhyj1bhdn1b46h895rgu5gbox1kwmqdjgpn

Этот asset используется как технический placeholder для переменных
image-slot'ов. Он не является контентным изображением.

В HTML его размер всегда задаётся по требованиям конкретного image-slot из
актуального компонента. Исходный размер файла placeholder не определяет
размер slot.

### Технические placeholder-assets, не являющиеся контентом

Следующие четыре UUID-файла из исторической библиотеки были техническими прозрачными image-slot'ами, а не контентными изображениями:

- `0c0a1d7c-18f0-4aa1-b397-0ba76d5356fc.png`
- `4fb7a47f-afbb-4bc9-88b9-9b5176d1b026.png`

Для production используется `6fea2cfd-955f-4aab-89d6-c3cb52deb89f.png`
как универсальный технический placeholder для переменных image-slot'ов.

Остальные три исторических placeholder-assets не используются как
production placeholder'ы.

### Прочие исторические локальные изображения

JPG/PNG из старых HTML-компонентов, которые являются примером конкретного контента выпуска, не являются постоянными assets библиотеки. В production-библиотеке они заменены переменными image-slot'ами.


### Миграция локальных служебных изображений

- `1f850b0a-e52e-4124-a271-a7c6d2a86c1a.png` — исторический локальный вариант стрелки; production использует канонический asset `f7008a36-9043-4ae5-a770-c3018cdc38f9.png` из раздела «Расписание».
- `02e7a020-9b6b-4e70-a8cf-7f822a0582fb.png` — исторический локальный логотип без отдельного актуального asset mapping; в production-компоненте `Баннеры/Вариант 10` используется канонический белый логотип `1d9f1700-a3ac-46f4-8ad2-6bc580b54ca0.png`.

Эти два UUID не являются переменными изображениями текущего выпуска и не должны возвращаться в список SMM.
