# README.md v2

## Структура писем

- Письмо начинается с hero-блока:
  - крупное изображение;
  - главный заголовок;
  - короткий подзаголовок.
- После hero следует вводный текст, объясняющий тему выпуска.
- Затем размещается главный материал выпуска.
- После него идут дополнительные материалы одинакового уровня.
- Если в выпуске несколько мероприятий, после основных материалов размещается расписание.
- Письмо заканчивается служебным футером (контакты, соцсети, отписка).

---

## Правила выбора компонентов

- Hero используется всегда.
- Первый материал после hero — самый важный материал выпуска.
- Каждый самостоятельный материал оформляется отдельной карточкой.
- Для подборок мероприятий используется блок расписания.
- Для каждого материала используется собственная CTA-кнопка.
- Изображение сопровождает практически каждую карточку.

---

## Правила порядка блоков

Всегда соблюдается следующий порядок:

1. Hero.
2. Вступительный текст.
3. Главный материал.
4. Дополнительные материалы.
5. Расписание мероприятий (если есть).
6. Футер.

Главный материал никогда не располагается после подборки второстепенных событий.

---

## Правила написания заголовков

- Обычно 3–8 слов.
- Заголовок максимально конкретный.
- Используются существительные и названия тем.
- Часто используется двоеточие.
- Допустимы перечисления.
- Подзаголовок всегда раскрывает тему заголовка, а не повторяет её.

---

## Правила длины текстов

### Лид

- 1–2 коротких абзаца.

### Карточка

- примерно 40–90 слов;
- 1–3 коротких абзаца.

Тексты не перегружаются историческими деталями и концентрируются на ценности мероприятия.

---

## Правила CTA

- Один CTA на одну карточку.
- CTA располагается после описания.
- Используются короткие глагольные формулировки.

Типичные варианты:

- Купить билет
- Подробнее
- Записаться
- Смотреть программу
- Узнать больше

---

## Правила ссылок

- Каждая карточка содержит собственную ссылку.
- Используются единообразные UTM-параметры.
- Не используются ссылки без сопровождающего текста.
- CTA является основным способом перехода.

---

## Правила использования изображений

- Hero всегда содержит крупное изображение.
- Практически каждая карточка сопровождается изображением.
- Изображение располагается перед текстом карточки.
- Одно изображение соответствует одному материалу.

---

## Правила формирования расписания

Если письмо содержит несколько событий:

- используется единый блок расписания;
- каждое событие оформляется одинаково;
- для каждого события указываются:
  - дата;
  - время;
  - название;
  - краткое описание;
  - CTA.

---

## Повторяющиеся закономерности

- Один главный материал открывает выпуск.
- Далее следуют материалы второго уровня.
- Используется повторяющийся ритм:

```
изображение
↓
заголовок
↓
описание
↓
CTA
```

- Абзацы короткие.
- Карточки имеют одинаковую структуру.
- CTA присутствует практически у каждого самостоятельного материала.

---

## Исключения

- Не каждый выпуск содержит расписание мероприятий. Тематические письма могут состоять только из главного материала и нескольких связанных карточек.
- В отдельных выпусках главным материалом становится путешествие или специальный проект вместо городской экскурсии.
- Количество дополнительных карточек варьируется в зависимости от темы выпуска.
