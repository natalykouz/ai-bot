# Hero

**Обязательный.**

Используется всегда.

### Поля

- image
- title
- subtitle

### Допустимое количество повторений

- 1 на письмо

### Ограничения

- располагается первым блоком письма;
- содержит крупное изображение;
- открывает основную тему выпуска.

### Что нельзя делать

- использовать более одного Hero;
- размещать после других блоков;
- использовать без изображения.

---

# Intro

**Обязательный.**

Используется сразу после Hero.

### Поля

- text

### Допустимое количество повторений

- 1 на письмо

### Ограничения

- располагается непосредственно после Hero;
- состоит из 1–2 коротких абзацев;
- вводит читателя в тему выпуска.

### Что нельзя делать

- переносить после основного материала;
- заменять перечнем карточек или расписанием.

---

# Card

**Обязательный.**

Используется для каждого самостоятельного материала выпуска.

### Поля

- image
- title
- text
- cta
- link

### Допустимое количество повторений

- от 1 до неограниченного количества

### Ограничения

- каждая карточка описывает один материал;
- изображение располагается перед текстом;
- описание состоит примерно из 40–90 слов;
- CTA располагается после описания;
- каждая карточка содержит собственную ссылку;
- первый экземпляр блока является главным материалом выпуска;
- остальные карточки располагаются после главного материала.

### Что нельзя делать

- объединять несколько материалов в одной карточке;
- использовать несколько CTA для одной карточки;
- использовать карточку без ссылки;
- использовать карточку без CTA;
- менять порядок элементов внутри карточки.

# Расписание

**Опциональный блок.** Используется, если письмо содержит мероприятия.

Расписание состоит из секций по календарным датам:
- одна секция = одна дата;
- внутри секции — события этой даты;
- секции идут по календарным датам по возрастанию.

Одна секция даты содержит от 1 до 20 событий.

Если после применения основных фильтров на дату подходит более 20 событий, в письмо включаются 20 событий с максимальным количеством свободных билетов. Остальные события этой даты не включаются. Вторую секцию той же даты не создавать.

Отбор по количеству свободных билетов выполняется до итоговой сортировки. После отбора события внутри даты располагаются по времени начала по возрастанию.
